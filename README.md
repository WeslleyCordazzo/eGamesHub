# eGamesHub

O eGamesHub é um site sobre e-sports, criado para apresentar informações sobre jogos competitivos e campeonatos.

O projeto foi desenvolvido como atividade do curso Técnico em Informática para Internet do **IFC Concórdia**, utilizando HTML e CSS.

## Sobre o projeto

O site apresenta:

* Informações sobre e-sports;
* Jogos competitivos;
* Campeonatos de e-sports;
* Algumas características dos jogos e das competições.

O objetivo do projeto foi colocar em prática os conhecimentos de desenvolvimento de páginas web, principalmente HTML, CSS e organização de um site.

## Tecnologias utilizadas

* HTML
* CSS
